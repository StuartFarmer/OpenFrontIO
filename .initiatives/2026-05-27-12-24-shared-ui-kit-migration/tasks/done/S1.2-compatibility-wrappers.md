# S1.2. Compatibility Wrappers

## Deliverable

D2. Compatibility Wrappers And Migration Path

## Objective

Keep existing call sites stable while introducing shared primitives behind legacy helpers where practical.

## Scope

Evaluate and adapt:

- `src/client/components/baseComponents/Button.ts`
- `src/client/components/baseComponents/Modal.ts`
- `src/client/components/ui/ActionButton.ts`
- `src/client/components/ui/Divider.ts`
- `src/client/components/ui/ModalHeader.ts`

## Acceptance Criteria

- Existing attributes and custom events remain compatible.
- Compatibility wrappers are thin and documented as migration helpers.
- New code has clear preferred shared primitive imports.

## Validation

```bash
npx tsc --noEmit
```
