# S6.2. Static UI Drift Check

## Deliverable

D7. Guardrails, Cleanup, And Documentation

## Objective

Add a guardrail that flags new ad hoc UI styling in component files when a shared primitive should be used.

## Scope

- Add a lightweight static scan or lint-style test.
- Flag obvious raw modal/button/input/range/table surface patterns in `src/client/components`.
- Allow explicit exceptions for generated, third-party, or intentionally low-level primitive code.

## Acceptance Criteria

- The check is low-noise and useful.
- Exceptions are documented and local.
- The check can run in local validation.

## Validation

```bash
npx tsc --noEmit
```
