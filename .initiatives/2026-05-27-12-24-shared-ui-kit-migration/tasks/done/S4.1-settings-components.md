# S4.1. Settings Components

## Deliverable

D5. Settings, Clan, Leaderboard, Ranking, And Stats Migration

## Objective

Convert settings controls and user settings modal content to shared form primitives.

## Scope

Review and migrate:

- `src/client/UserSettingModal.ts`
- `src/client/components/baseComponents/setting/SettingKeybind.ts`
- `src/client/components/baseComponents/setting/SettingNumber.ts`
- `src/client/components/baseComponents/setting/SettingSelect.ts`
- `src/client/components/baseComponents/setting/SettingSlider.ts`
- `src/client/components/baseComponents/setting/SettingToggle.ts`

## Acceptance Criteria

- Current settings persist and update exactly as before.
- Keyboard capture behavior remains intact.
- Range/select/toggle components use shared primitives and preserve labels/tooltips.

## Validation

```bash
npx tsc --noEmit
npx vitest run tests/client/components/UiComponents.test.ts
```

## Status

Done.

## Notes

- Settings slider/select/number/toggle wrappers now compose `ui-range`, `ui-select`, `ui-input`, and `ui-toggle`.
- Existing wrapper event contracts are preserved, including `CustomEvent("change", { detail: { value } })` for sliders, selects, and numbers.
- Keybind keyboard capture remains raw; reset/unbind actions now use `ui-button`.
