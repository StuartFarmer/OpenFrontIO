# S1.4. Primitive Validation

## Deliverable

D1. Shared App UI Primitive Foundation

## Objective

Add focused validation for the shared primitives and compatibility wrappers before broad migration starts.

## Scope

- Add lightweight tests or catalog coverage for shared primitives.
- Verify modal focus, close, disabled button, range input, select, and form-row behavior.
- Confirm compatibility wrappers preserve legacy usage.

## Acceptance Criteria

- A targeted test or catalog check fails if core primitive registration breaks.
- Compatibility wrappers are covered by at least smoke-level validation.

## Validation

```bash
npx tsc --noEmit
npx vitest run tests/client/hud/HudCatalog.test.ts
```
