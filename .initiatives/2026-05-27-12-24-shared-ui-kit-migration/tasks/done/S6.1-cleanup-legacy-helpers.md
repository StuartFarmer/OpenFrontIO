# S6.1. Cleanup Legacy Helpers

## Deliverable

D7. Guardrails, Cleanup, And Documentation

## Objective

Remove or deprecate duplicate legacy helpers after call sites have migrated.

## Scope

- Review `src/client/components/baseComponents`.
- Review thin helpers in `src/client/components/ui`.
- Remove only unused legacy paths.
- Keep compatibility wrappers when removal would risk unrelated behavior.

## Acceptance Criteria

- No migrated call site imports deprecated helpers unless intentionally documented.
- Unused duplicate styling code is removed where safe.
- Remaining compatibility wrappers state why they remain.

## Validation

```bash
npx tsc --noEmit
git diff --check
```
