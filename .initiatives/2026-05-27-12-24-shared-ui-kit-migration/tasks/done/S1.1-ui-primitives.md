# S1.1. Shared App UI Primitives

## Deliverable

D1. Shared App UI Primitive Foundation

## Objective

Create the generic UI primitive layer under `src/client/components/ui` so app pages, modals, lobby UI, settings, and in-game modal surfaces can share composable building blocks.

## Scope

Add or expand primitives for:

- Surface and panel structure.
- Modal shell, header, body, footer, and close button.
- Button, icon button, action group, and button group.
- Label, pill, badge/chip, alert, loading, and empty state.
- Input, textarea, select, range, toggle, checkbox, and form row.
- Stat, stat grid, table/list rows, and menu/dropdown support where needed.

## Touchpoints

- `src/client/components/ui`
- `src/client/hud/ui` only where shared code extraction is low risk.

## Acceptance Criteria

- Primitives use stable attributes/events suitable for Lit composition.
- Components support disabled states, labels, focus styles, and responsive sizing.
- No game behavior is moved into primitives.
- Exports are discoverable through a shared barrel path.

## Validation

```bash
npx tsc --noEmit
```
