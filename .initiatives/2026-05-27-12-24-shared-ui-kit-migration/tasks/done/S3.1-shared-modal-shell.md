# S3.1. Shared Modal Shell

## Deliverable

D4. Root App Modal And Account Surface Migration

## Objective

Establish the shared modal shell pattern used by root app modals.

## Scope

- Ensure `BaseModal` and `<o-modal>` compatibility are aligned with shared modal primitives.
- Define common modal slots/parts for header, body, footer, close actions, and scrolling.
- Preserve current modal lifecycle behavior.

## Acceptance Criteria

- Existing modal callers can migrate incrementally.
- Focus, close, overlay click, and Escape behavior are preserved.
- Modal layout supports long content without overflowing the viewport.

## Validation

```bash
npx tsc --noEmit
```
