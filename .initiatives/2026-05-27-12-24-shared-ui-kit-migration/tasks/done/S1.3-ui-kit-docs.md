# S1.3. UI Kit Documentation

## Deliverable

D1. Shared App UI Primitive Foundation

## Objective

Document how shared UI primitives should be used across app UI and how they relate to HUD-specific components.

## Scope

Update or add docs covering:

- `src/client/components/ui` ownership and naming.
- `src/client/hud/ui` boundary.
- Component examples for common modal, form, stat, table, and action patterns.
- Migration rules for preserving behavior.

## Touchpoints

- `docs/HUD_UI_CATALOG_PLAN.md`
- Initiative docs as needed.

## Acceptance Criteria

- Developers can tell when to use shared app primitives versus HUD-specific components.
- Docs explicitly discourage new ad hoc modal/button/range/table styling in component files.

git diff --check
