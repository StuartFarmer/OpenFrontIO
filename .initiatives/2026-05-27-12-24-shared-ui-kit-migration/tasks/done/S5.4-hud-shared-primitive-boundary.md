# S5.4. HUD Shared Primitive Boundary

## Deliverable

D6. HUD Modal And In-Game Overlay Migration

## Objective

Clarify and enforce the boundary between generic shared primitives and HUD-specific components.

## Scope

- Audit `src/client/hud/ui` for generic components that should compose from `src/client/components/ui`.
- Keep HUD-specific components in place when they encode game HUD layout or semantics.
- Document exceptions.

## Acceptance Criteria

- Shared primitives are not duplicated under HUD without reason.
- HUD-specific components remain stable for existing control panel and overlay usage.
- The boundary is documented for future work.
