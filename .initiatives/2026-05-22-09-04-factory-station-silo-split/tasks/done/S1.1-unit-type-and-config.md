## Purpose

Introduce Rail Station and Silo as first-class deterministic unit types with build costs, resource-cost splits, and buildable structure membership.

## Scope
- In: `UnitType`, structure/buildable unit groups, `UnitParamsMap`, config `unitInfo()`, resource costs, disabled-unit compatibility.
- Out: Moving Factory rail/capacity behavior; UI menu changes; renderer atlas changes.

## Touchpoints

- Modify: `src/core/game/Game.ts`, `src/core/configuration/Config.ts`, tests covering config/buildability as needed.

- [ ] Both have structure-like cost, resource cost, construction duration, and upgrade policy.
