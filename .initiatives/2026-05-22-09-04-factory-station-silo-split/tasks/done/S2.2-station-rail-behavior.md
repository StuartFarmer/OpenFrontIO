# S2.2: Station Rail Behavior

**Status**: DONE
**Wave**: W2
**Track**: Rail
**Supports**: D2
**Effort**: L
**Dependencies**: W1

## Purpose

Move Factory's train-station and rail-connectivity behavior onto Rail Station.

## Scope
- In: construction completion execution for Rail Station, rail station attachment, rail neighbor lists, ghost rail paths, train spawn-rate ownership, train stop handlers.
- Out: Silo capacity; UI menus; unrelated rail rendering style.

## Touchpoints
- Create: likely `src/core/execution/RailStationExecution.ts` or equivalent.
- Modify: `src/core/execution/ConstructionExecution.ts`, `src/core/execution/FactoryExecution.ts`, `src/core/execution/TrainStationExecution.ts`, `src/core/game/RailNetworkImpl.ts`, `src/core/game/TrainStation.ts`, rail tests.

## Acceptance Criteria
- [ ] Rail Station creates a runtime train station and connects nearby eligible stations.
- [ ] Factory construction no longer creates a runtime train station.
- [ ] Ghost rail previews and nearby station eligibility use Rail Station rather than Factory as the rail anchor.
- [ ] Train spawning is either moved to Rail Station for behavior preservation or explicitly disabled with tests documenting the intended no-spawn behavior.

## Test Plan
- `npx vitest run tests/core/game/RailNetwork.test.ts tests/core/game/TrainStation.test.ts` - rail graph and cluster behavior.
- `npx vitest run tests/client/render/frame/derive/ConnectedRailroads.test.ts` - connected/disconnected rail overlay derivation.
