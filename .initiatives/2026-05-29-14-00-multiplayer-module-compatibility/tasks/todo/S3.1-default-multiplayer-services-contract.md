**Status**: TODO

## Purpose
Define the default multiplayer service hooks that every registered game module receives and implements with module-owned schemas.

## Scope
- In: Default service hooks for local play, remote multiplayer, public lobbies, private lobbies, replay, archive, winner/end-state handling, hash/desync, and module validation.
- In: OpenFront service implementation matching current behavior.
- In: Foundation minimal service implementation that can start local-first without creating opt-out booleans.
- Out: Full game module registry implementation beyond what this initiative requires.

## Touchpoints
- Create: `src/core/modules/GameModuleRuntime.ts`.
- Modify: OpenFront adapter/module registration when available.
- Modify: Foundation module registration when available.

## Acceptance Criteria
- [ ] Default services are resolved through module registry lookups.
- [ ] Foundation can start with minimal service payloads while preserving the same path to remote/public multiplayer.
- [ ] OpenFront implements `GameModuleRuntime` without behavior changes.
