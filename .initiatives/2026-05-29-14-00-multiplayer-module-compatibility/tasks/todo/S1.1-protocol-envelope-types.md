**Status**: TODO
**Wave**: W1
**Track**: A
**Supports**: D1
**Effort**: M
**Dependencies**: None

## Purpose
Define generic module-aware protocol envelope types and schemas beside the existing OpenFront schemas.

## Scope
- In: Start, prestart, client intent, stamped intent, turn, hash, error, and lobby metadata envelope definitions.
- In: `moduleId` defaulting semantics for compatibility.
- Out: Migrating all callers to the new schemas.

## Touchpoints
- Create: `src/core/protocol/ModuleProtocol.ts` or equivalent.
- Modify: `src/core/Schemas.ts` only through additive exports or bridge imports.

## Acceptance Criteria
- [ ] Envelope types allow `unknown` module config/payloads behind validators.
- [ ] Turn envelopes preserve ordered `turnNumber` and server-stamped `clientID`.
- [ ] OpenFront payloads can be represented without losing current fields.

## Test Plan
- `module_protocol_accepts_unknown_payloads` - proves envelopes validate structure but not module payload meaning.
- `module_turn_preserves_stamped_client_identity` - proves client identity is server-owned.
