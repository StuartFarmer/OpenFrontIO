## Purpose
Add adapters that normalize current OpenFront `GameStartInfo`, `Intent`, `StampedIntent`, and `Turn` shapes into generic module envelopes and back.

## Scope
- In: Pure conversion helpers for OpenFront protocol compatibility.
- In: Compatibility rule that missing `moduleId` means `openfront`.
- Out: Moving OpenFront schemas into `src/games/openfront`.

## Touchpoints
- Create: `src/core/protocol/OpenFrontProtocolAdapter.ts` or module-local equivalent.
- Modify: `src/core/Schemas.ts` additively if exports need to be shared.

## Acceptance Criteria
- [ ] Existing OpenFront messages round-trip through adapter helpers.
- [ ] Old persisted/replay turns can be normalized without changing payload meaning.
- [ ] Adapter does not import server or client runtime code.
