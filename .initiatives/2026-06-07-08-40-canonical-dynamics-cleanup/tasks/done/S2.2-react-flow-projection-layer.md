# S2.2: React Flow Projection Layer

**Status**: DONE
**Wave**: W2
**Track**: Editor projection
**Supports**: D2
**Effort**: Large
**Dependencies**: S2.1

## Purpose

Move React Flow node/edge conversion into a UI mapping layer so canonical saved
systems are not React Flow-shaped.

## Scope

- In: Schema-to-React-Flow projection, React-Flow-to-schema edit extraction,
  focused mapping tests.
- Out: Replacing React Flow or redesigning the editor.

## Touchpoints

- Create:
  - `src/games/foundation/dynamics/react/FoundationDynamicsReactFlowMapping.ts`
- Modify:
  - `src/games/foundation/dynamics/FoundationDynamicsModel.ts`
  - `src/games/foundation/client/FoundationDynamicsPage.ts`
  - `src/games/foundation/dynamics/react/FoundationDynamicsReactBridge.tsx`
  - `tests/games/foundation/dynamics/FoundationDynamicsReactFlowMapping.test.ts`

## Acceptance Criteria

- [x] React Flow `Node`/`Edge` types are isolated to React/UI mapping modules.
- [x] Page can render and edit systems through projection helpers.
- [x] Mapping round-trips preserve definition, scenario, and view metadata.

## Test Plan

- `react_flow_projection_round_trip` - schema/view projects to React Flow and
  back without losing graph data.
- `react_flow_projection_keeps_controls_in_view` - input control metadata stays
