# S3.1: Graph Runtime Binding Contract

**Status**: DONE
**Wave**: W3
**Track**: Binding contract
**Supports**: D3
**Effort**: Large
**Dependencies**: W2

## Purpose

Define the standard runtime binding shape for graph-backed systems: read game
state into graph inputs/sinks, step compiled dynamics, and apply outputs.

## Scope

- In: Generic binding interfaces and a small test fixture.
- Out: Migrating OpenFront StockFlow models.

## Acceptance Criteria

- [x] Binding contract can run a compiled dynamics system inside a scheduled
      `GameSystem`.
- [x] Binding contract separates read, step, and apply responsibilities.
- [x] Test fixture proves imperative systems remain independently ordered.
