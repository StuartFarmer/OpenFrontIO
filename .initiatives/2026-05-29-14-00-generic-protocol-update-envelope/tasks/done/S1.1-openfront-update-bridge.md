**Status**: DONE

**Supports**: D2, D3

## Purpose

Wrap legacy OpenFront `GameUpdateViewData` into `EngineUpdateEnvelope` and unwrap it back for existing OpenFront client consumers.

## Scope
- In:
  - Convert `packedTileUpdates` to generic map tile state delta.
  - Preserve optional `packedMotionPlans`.
  - Carry legacy `updates` and `playerNameViewData` as OpenFront module events or a legacy payload event.
  - Preserve `tickExecutionDuration` and `pendingTurns` under metrics.
- Out:
  - No HUD migration away from `GameUpdateType`.
  - No renderer protocol redesign.

## Touchpoints
- Create:
  - `src/core/protocol/openfront/*` or `src/games/openfront/protocol/*`
- Modify:
  - None outside bridge exports until W2.

## Acceptance Criteria

- [x] Bridge explicitly marks legacy fields as transitional.
