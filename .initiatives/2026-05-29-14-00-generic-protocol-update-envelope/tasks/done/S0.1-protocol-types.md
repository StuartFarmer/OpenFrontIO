## Purpose

Create the shared engine protocol contracts that separate envelope routing from module-owned payload meaning.

## Alignment

- Initiative goal: Make generic start, turn, intent, update, event, error, metrics, and transferable envelopes the primary engine protocol API.
- Deliverable: D1 Engine Protocol Contracts.
- Demo check: protocol tests plus TypeScript compile for the new protocol files.
- Wave rationale: Establish the generic contract baseline before OpenFront bridge, worker, or runtime migration work begins.

## Scope

- In:
  - Define generic start, player, turn, stamped intent, update, module event, error, metrics, and map delta envelope types.
  - Add a helper shape for discovering transferable buffers in update envelopes.
  - Keep payloads as `unknown` or validator-owned generics.
  - Export Zod schemas for envelope boundaries while preserving module-owned payloads as `unknown`.
- Out:
  - No runtime call site migration.
  - No OpenFront bridge implementation.
  - No replay/archive migration.
  - No capability booleans for default services.

## Context and Rationale

- Why this exists: Existing shared transport types are coupled to OpenFront payloads and update enums.
- Constraints: Protocol files must not import OpenFront `Game`, `Intent`, `GameConfig`, or `GameUpdateType`.
- Trade-offs: Payload validation is intentionally shallow here; game modules validate their own payload schemas.
- Chosen approach: Use `moduleId` as the stable module routing identifier and Zod schemas for envelope shape validation.

## Behavior and Requirements

### B1: Module-owned payload boundary

- Given: A start, intent, or module event payload with arbitrary object contents.
- When: The generic protocol schema validates the envelope.
- Then: The envelope shape is checked and the payload remains module-owned `unknown`.

### B2: Transferable map buffers

- Given: An update envelope with typed-array map deltas.
- When: Transport code asks for transferables.
- Then: The helper returns the underlying `ArrayBuffer` instances without interpreting map semantics.
