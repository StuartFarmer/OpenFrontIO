# S1.1: Delivery Manifest Helper

**Status**: DONE
**Wave**: W1
**Track**: Core math
**Supports**: D1
**Effort**: Medium
**Dependencies**: None

## Purpose

Create a pure helper for delivery-time resource transfer manifests, using equal target blend by default and preserving total resources.

## Scope
- In: Add a core resource-trade helper module.
- In: Add tests for surplus, deficit, reciprocal exchange, max payload scaling, and empty deliveries.
- Out: Do not change train or ship delivery behavior in this ticket.
- Out: Do not add route capacity, route scoring, fuel costs, or UI.

## Touchpoints
- Create: `src/core/game/ResourceTrade.ts`, `tests/core/game/ResourceTrade.test.ts`
- Modify: None expected

## Acceptance Criteria
- [ ] A one-way manifest moves only resources the exporter has above target and importer has below target.
- [ ] Reciprocal exchange returns equal-total manifests for both players.
- [ ] Max payload scales manifests down without creating unavailable resources.
- [ ] Empty delivery returns zero manifests when there is no matching surplus/deficit.

## Test Plan
- `calculates a one-way manifest from exporter surplus and importer deficit` - proves basic matching.
- `scales reciprocal exchange to equal totals` - proves one-resource-for-one-resource behavior.
- `returns zero exchange when either side lacks useful surplus` - proves empty delivery behavior.
- `caps inbound resources by receiver headroom` - proves capacity safety.
