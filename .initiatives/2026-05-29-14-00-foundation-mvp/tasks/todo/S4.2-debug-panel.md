# S4.2: Debug Panel

**Status**: TODO
**Wave**: W4
**Track**: B - debug UI
**Supports**: D5
**Effort**: Medium
**Dependencies**: W2

## Purpose
Provide a small Foundation debug panel that reports the MVP state while placement/rendering is being proven.

## Scope
- In: Lit or simple DOM panel showing map size, placement status, selected tile, claimed tile count, tick/update count, and last command/update status.
- Out: OpenFront HUD components, build menu, leaderboard, chat, settings modal, population/food controls.

## Touchpoints
- Create: `src/games/foundation/client/FoundationDebugPanel.ts`
- Modify: `src/games/foundation/client/FoundationClient.ts` or `FoundationPage.ts` to feed state.

## Acceptance Criteria
- [ ] Debug panel is visible on the Foundation route.
- [ ] Panel updates after click placement.
- [ ] Panel text is compact and does not describe unrelated app features.
- [ ] Panel does not import OpenFront HUD layer components.

## Test Plan
- `foundation_debug_panel_renders_initial_state` - validates initial map/unplaced state.
- `foundation_debug_panel_updates_after_placement` - validates placed/claimed/tick state render.

## Working Notes
- Keep styling small and local; do not broaden the shared UI kit in this MVP.
