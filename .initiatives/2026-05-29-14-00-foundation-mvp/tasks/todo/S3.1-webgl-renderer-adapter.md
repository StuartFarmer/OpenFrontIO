**Status**: TODO
**Wave**: W3
**Track**: A - renderer adapter
**Supports**: D4

## Purpose
Create the minimal Foundation adapter around the existing custom WebGL renderer facade.

## Scope
- In: canvas creation/disposal, `src/client/render/gl/GameView` construction, terrain byte upload, minimal palette/player registration, tile/trail state upload.
- Out: OpenFront `ClientGameRunner`, `WebGLFrameBuilder`, `GameView` mirror, HUD renderer, structures, units, names, railroads, attacks, nukes.

## Touchpoints
- Create: `src/games/foundation/renderer/FoundationWebGLAdapter.ts`
- Create: `src/games/foundation/renderer/FoundationFrameAdapter.ts` if a minimal frame object is useful.
- Modify: None expected outside Foundation unless a tiny reusable canvas helper is extracted.

## Acceptance Criteria
- [ ] Adapter uses `src/client/render/gl` facade rather than Pixi.
- [ ] Adapter can upload initial blank terrain/state.
- [ ] Adapter can apply placement tile-state updates.
- [ ] Renderer `PlayerStatic`, `FrameData`, or placeholder OpenFront-shaped fields are isolated inside adapter code.
- [ ] Adapter has an explicit `dispose()` path.

## Test Plan
- `foundation_webgl_adapter_builds_renderer_config` - validates renderer config/player palette inputs without requiring real WebGL.
- `foundation_webgl_adapter_applies_tile_delta` - validates delta conversion from Foundation updates to renderer upload calls using a mocked view.
