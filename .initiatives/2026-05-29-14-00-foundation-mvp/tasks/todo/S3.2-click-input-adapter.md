**Status**: TODO

## Purpose
Translate user clicks on the Foundation canvas into Foundation placement commands without using OpenFront `InputHandler`.

## Scope
- In: pointer listener setup/cleanup, screen-to-world conversion, tile bounds checks, command construction.
- Out: radial menu, drag attack, boat movement, build preview, hover panels, OpenFront spawn-phase behavior.

## Touchpoints
- Create: `src/games/foundation/client/FoundationInputAdapter.ts`
- Modify: Foundation renderer adapter only if it should expose screen/world conversion directly.

## Acceptance Criteria
- [ ] Left click maps to a valid tile ref when inside map bounds.
- [ ] Out-of-bounds clicks are ignored or surfaced as debug state without runtime mutation.
- [ ] Input cleanup removes listeners.
- [ ] No dependency on `src/client/InputHandler.ts`.

## Test Plan
- `foundation_input_click_maps_to_tile_command` - validates click-to-command conversion with mocked screen/world mapping.
- `foundation_input_ignores_out_of_bounds_click` - validates invalid clicks do not dispatch placement.
