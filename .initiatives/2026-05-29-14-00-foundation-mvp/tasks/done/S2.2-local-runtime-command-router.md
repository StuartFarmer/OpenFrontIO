# S2.2: Local Runtime Command Router

**Status**: DONE
**Wave**: W2
**Track**: Runtime
**Supports**: D3
**Effort**: Medium
**Dependencies**: S2.1, W1

## Purpose

Implement a local single-player Foundation runtime that processes placement commands, mutates Foundation state, advances ticks, and emits updates.

This ticket wires the S2.1 envelopes to the W1 placement domain. The runtime should be usable directly by a local client today and easy to wrap in a worker later because commands and updates cross a narrow dispatch boundary.

## Scope

- In: runtime state, command dispatch, placement command execution, tick/update count, map changed-tile reporting.
- Out: Worker integration, network transport, deterministic auto-start placement, population/food systems.
- Out: OpenFront `GameRunner`, `Executor`, `Intent`, `GameView`, `Nation`, build, warship, alliance, spawn, rail, bot, and win-check imports.

## Acceptance Criteria

- [x] Runtime initializes a blank Foundation world with one unplaced player.
- [x] Runtime accepts one click placement command and produces ownership tile deltas.
- [x] Runtime does not install OpenFront spawn timer, win check, rails, bots, nations, or executions.
- [x] Runtime records enough state for the debug panel: tick/update count, selected tile, claimed tile count, placement status.
- [x] Runtime mutates only the Foundation semantic-free tile state for placement and reports changed tile refs/states.
- [x] Second placement policy is explicit and tested.
