# S1.2: Semantic-Free Tile Map

**Status**: DONE
**Wave**: W1
**Track**: A - map primitive
**Supports**: D2
**Effort**: Medium
**Dependencies**: S1.1

## Purpose

Implement Foundation's first `EngineTileMap`-style primitive with raw buffers and tile addressing only.

## Scope

- In: map dimensions, ref/coordinate conversion, valid-ref checks, terrain buffer, state buffer, blank grass generator, module-owned terrain query layer.
- Out: `isLand()` on the base map, OpenFront `GameMap`, pathfinding, shoreline/ocean/fallout/defense semantics.

## Touchpoints

- Create: `src/games/foundation/domain/EngineTileMap.ts`
- Create: `src/games/foundation/domain/FoundationTerrain.ts`
- Create: `src/games/foundation/domain/createFoundationMap.ts`
- Modify: None expected outside Foundation.

## Acceptance Criteria

- [x] Base map exposes `width()`, `height()`, `ref()`, `x()`, `y()`, `isValidRef()`, `terrainBuffer()`, and `stateBuffer()`.
- [x] Base map does not expose semantic queries such as `isLand`, `isGrass`, or passability.
- [x] Blank map generation fills terrain bytes consistently for renderer-compatible grass terrain.
- [x] Foundation terrain semantics live in a separate adapter/query module.

## Test Plan

- `foundation_map_generates_blank_grass_buffer` - validates terrain/state buffer sizes and initial values.
- `foundation_map_addressing_round_trips_refs` - validates ref/x/y conversion and invalid bounds behavior.
- `foundation_terrain_queries_are_module_owned` - validates grass query behavior without adding semantics to the base map.
