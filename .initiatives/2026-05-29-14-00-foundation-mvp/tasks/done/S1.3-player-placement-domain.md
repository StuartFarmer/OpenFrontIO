**Status**: DONE

## Purpose

Define Foundation's plain `Player` record and deterministic fixed-radius tile claim behavior.

## Scope

- In: `FoundationPlayer` record, owner id choice, placement state, fixed-radius tile collection, tile ownership writes.
- Out: population/food ticking, Nation naming, bots, teams, units, alliances, resources beyond placeholder fields if needed for future debug display.

## Touchpoints

- Create: `src/games/foundation/domain/FoundationPlayer.ts`
- Create: `src/games/foundation/domain/placePlayer.ts`
- Modify: None expected outside Foundation.

## Acceptance Criteria

- [x] Foundation uses a plain `Player` record, not OpenFront `PlayerInfo` or `PlayerImpl`.
- [x] Placement claims a fixed radius around the clicked tile.
- [x] Claimed tiles are clipped to valid map bounds.
- [x] Tile ownership writes use the map state buffer in a renderer-compatible way.
- [x] Repeated placement behavior is explicit: either ignored after first placement or replaces/moves the same player, according to implementation choice documented in code/tests.

## Test Plan

- `foundation_place_player_claims_fixed_radius` - validates owned tile count/shape for a center placement.
- `foundation_place_player_clips_radius_at_edges` - validates edge placements do not write invalid refs.
- `foundation_place_player_updates_player_record` - validates selected tile and claimed count are reflected in player state.
