**Status**: DONE
**Wave**: W2
**Track**: Ship trade
**Supports**: D3
**Effort**: Medium
**Dependencies**: S1.1

## Purpose

Change trade ship completion so the old `tradeShipGold` scalar is awarded as a blended total-resource payload based on the exporting player.

## Scope
- In: Update `complete()` in `src/core/execution/TradeShipExecution.ts`.
- In: Update trade ship tests to mock source/exporter resources and assert blended payloads.
- In: Add or update a captured ship completion test.
- Out: Do not change `Config.tradeShipGold`.
- Out: Do not change ship pathfinding, capture routing, or trade spawn rules.
- Out: Do not migrate event localization keys.

## Touchpoints
- Create: None
- Modify: `src/core/execution/TradeShipExecution.ts`, `tests/core/executions/TradeShipExecution.test.ts`

## Acceptance Criteria
- [ ] Normal source-owner payout uses the source owner's blend and total equals `tradeShipGold(...)`.
- [ ] Normal destination-owner payout uses the source owner's blend and total equals `tradeShipGold(...)`.
- [ ] Captured ship completion has explicit tested blend-source behavior.
- [ ] `boatArriveTrade` and `boatCapturedTrade` still receive the scalar trade value.
- [ ] Blend is computed before any recipient is paid.

## Test Plan
- `should complete trade and award blended resources` - updates normal completion coverage.
- `should complete captured trade and award captured cargo resources` - covers captured completion semantics.
