## Purpose

Create the shared primitive that converts a scalar trade value into a resource payload using an exporter's current resource proportions.

## Scope
- In: Add a helper to `src/core/game/Resources.ts`.
- In: Add focused helper tests in `tests/core/game/Resources.test.ts`.
- Out: Do not update train or ship call sites in this ticket.
- Out: Do not change `resourcesFromGoldAmount`.

## Touchpoints
- Create: None

## Acceptance Criteria
- [ ] `resourcesFromExportBlend(10000n, { food: 300n, energy: 200n, materials: 500n })` returns `{ food: 3000n, energy: 2000n, materials: 5000n }`.
- [ ] Rounding preserves exact total, for example total `10n` with equal stockpile returns a deterministic split totaling `10n`.
- [ ] Zero stockpile falls back to an even split totaling the input.
- [ ] Negative or zero trade values return a zero resource payload.

## Test Plan
- `resourcesFromExportBlend splits total by exporter blend` - proves proportional conversion.
- `resourcesFromExportBlend preserves totals through rounding` - proves no resource loss or overproduction.
- `resourcesFromExportBlend falls back when exporter has no stockpile` - proves zero-stockpile behavior.
