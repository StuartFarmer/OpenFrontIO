## Purpose
Design how the renderer can construct base-map passes separately from OpenFront-only passes after Foundation proves the minimal adapter.

## Scope
- In: Renderer profiles or composed pass groups for base map, OpenFront gameplay overlays, names, units, structures, railroads, FX, nukes, radial UI.
- Out: Immediate renderer rewrite.

## Touchpoints
- Create: Future design doc or implementation tickets.
- Modify: Future `src/client/render/gl/Renderer.ts` and pass construction code.

## Acceptance Criteria
- [ ] Base-map profile includes only terrain, ownership/territory, camera, and owner hit-testing.
- [ ] OpenFront profile composes all current pass groups and preserves draw order.
- [ ] Design avoids game-facing feature booleans as the main abstraction.
