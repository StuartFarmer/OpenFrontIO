## Purpose
Plan a Foundation-owned input path for camera movement and click-to-place without using OpenFront `InputHandler`.

## Scope
- In: Input overlay creation, pointer click detection, screen-to-world conversion, tile-ref conversion, simple pan/zoom or fit-map behavior.
- Out: OpenFront radial menu, build menu, emoji menu, warship selection, attack ratios, alliances, pause/game-speed keybinds.

## Touchpoints
- Create: Future `FoundationInputAdapter` or generic `MapInputSurface`.
- Modify: Existing OpenFront `InputHandler` only if extracting reusable helpers proves safe.

## Acceptance Criteria
- [ ] Click-to-place emits a Foundation event/intent with tile ref and screen/world coordinates.
- [ ] Camera can fit the map and support minimal pan/zoom behavior.
- [ ] Foundation input code has no dependency on OpenFront `UIState`.
