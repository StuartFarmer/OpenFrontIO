## Purpose
Define the Foundation-owned WebGL adapter boundary that can mount the custom renderer without constructing OpenFront client `GameView`.

## Scope
- In: Adapter class/function shape, construction inputs, cleanup contract, and module ownership.
- Out: Population/food simulation, multiplayer, OpenFront HUD mounting.

## Touchpoints
- Create: Future `src/games/foundation/client/FoundationWebGLAdapter.ts` or equivalent.
- Modify: Future module registry/client mount code, if available.

## Acceptance Criteria
- [ ] Adapter inputs are raw map dimensions, terrain buffer, tile-state buffer, palette/owner colors, and event callbacks.
- [ ] Adapter exposes cleanup/dispose.
- [ ] Adapter does not import `src/core/game/GameView` or OpenFront `PlayerView`.
