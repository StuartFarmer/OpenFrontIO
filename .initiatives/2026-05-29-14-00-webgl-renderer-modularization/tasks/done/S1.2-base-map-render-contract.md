## Purpose

Design the minimal renderer contract Foundation needs without exposing OpenFront frame or gameplay concepts.

## Scope

- In: TypeScript interface shape for terrain bytes, tile state, tile deltas, terrain deltas, palette entries, camera methods, and screen-to-world conversion.
- Out: Units, structures, railroads, trails, nukes, names, alliances, SAM radius, radial menus, OpenFront `GameView`.

## Acceptance Criteria

- [x] Contract can represent blank grass terrain and one player ownership color.
- [x] Contract can upload full tile-state buffer and changed tile refs/states.
- [x] Contract can support click-to-place through screen-to-world or screen-to-tile conversion.
- [x] Contract contains no terrain semantic helpers such as `isLand()` or `isGrass()`.
