# S3.1: Foundation Adapter Skeleton

**Status**: DONE
**Wave**: W3
**Track**: Shared setup
**Supports**: D4
**Effort**: Medium
**Dependencies**: S2.1

## Purpose

Define the Foundation-owned WebGL adapter boundary that can mount the custom renderer without constructing OpenFront client `GameView`.

## Scope

- In: Adapter class/function shape, construction inputs, cleanup contract, injected test target support, and renderer-owned namespace.
- Out: Population/food simulation, multiplayer, OpenFront HUD mounting, OpenFront `GameView`, OpenFront `FrameData`, route wiring, or Foundation runtime edits.

## Touchpoints

- Create: `src/client/render/base-map/BaseMapWebGLAdapter.ts`.
- Create: `src/client/render/base-map/Types.ts`.
- Create: `src/client/render/base-map/index.ts`.
- Modify: None outside the renderer-owned adapter namespace unless validation exposes a type-only export need.

## Acceptance Criteria

- [x] Adapter inputs are raw map dimensions, terrain buffer, tile-state buffer, palette/owner colors, and event callbacks.
- [x] Adapter exposes cleanup/dispose.
- [x] Adapter does not import `src/core/game/GameView` or OpenFront `PlayerView`.
- [x] Adapter can be constructed against a fake target for unit tests without browser-only WebGL.

## Test Plan

- `npm exec vitest run tests/client/render/base-map/base-map-adapter.test.ts` - construction/dispose and import-boundary checks.
- `npm exec tsc -- --noEmit` - source type validation.
