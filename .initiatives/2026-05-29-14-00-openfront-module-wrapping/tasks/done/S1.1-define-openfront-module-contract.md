# S1.1: Define OpenFront Module Contract

**Status**: DONE
**Wave**: W1
**Track**: Boundary
**Supports**: D1
**Effort**: M
**Dependencies**: None

## Purpose
Define a small module contract that can wrap current OpenFront behavior without encoding OpenFront features as engine requirements.

## Scope
- In: Module interfaces for server/client lifecycle, OpenFront module entry point shape, context types needed by existing startup paths.
- Out: Foundation implementation, generic update envelope migration, renderer modularization.

## Touchpoints
- Create: `src/games/openfront/OpenFrontModule.ts`
- Create: `src/games/openfront/types.ts`
- Modify: boundary imports only where the module is selected.

## Acceptance Criteria
- [x] Contract exposes lifecycle methods such as server runner creation and client mount.
- [x] Contract does not include feature booleans such as build menu, alliances, or warships.
- [x] OpenFront module can be imported without side effects beyond current expected registration.

## Test Plan
- `module_contract_typecheck` - TypeScript build verifies module contract and OpenFront module compile.
- `openfront_module_shape_test` - Verifies OpenFront module exposes expected id and lifecycle methods.
