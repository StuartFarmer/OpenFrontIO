**Hardened**: 2026-05-21

## Purpose

Add pure helper functions for per-resource capacity math, capped deltas, and troop-shaped regen calculations.

## Scope
- In: Helpers for clamping positive resource deltas to capacity, computing remaining capacity, and applying the troop-shaped regen curve to a current/max pair.
- Out: Player tick integration, UI state, terrain production, resource-specific costs.

## Context and Rationale
- Why this exists: Later tickets need deterministic resource-capacity primitives before `Config` and `PlayerExecution` integrate them.
- Constraints: Resource stockpiles are `bigint`, while the existing troop curve is `number` based.
- Trade-offs: The helper will use the same numeric curve shape as troops and floor back to `bigint`; exact giant-number precision is not a target for this gameplay scale.
- Chosen approach: Keep helpers pure in `Resources.ts` and cover them directly in `tests/core/game/Resources.test.ts`.

## Behavior and Requirements
### B1: Remaining capacity is per resource
- Given: current resources and capacity resources.
- When: remaining capacity is computed.
- Then: each resource returns `max(capacity - current, 0n)` independently.

### B2: Passive deltas clamp to storage
- Given: current resources, requested positive deltas, and capacity.
- When: clamping is applied.
- Then: no returned resource delta exceeds available capacity for that resource.

### B3: Regen follows troop curve shape
- Given: current amount and capacity.
- When: regen is computed.
- Then: it returns `0n` at/above cap and otherwise follows the troop-style accelerating-then-slowing curve.
