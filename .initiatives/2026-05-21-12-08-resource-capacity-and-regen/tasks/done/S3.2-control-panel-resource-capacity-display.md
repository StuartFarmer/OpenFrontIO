# S3.2: Control Panel Resource Capacity Display

**Status**: DONE
**Wave**: W3
**Track**: UI
**Supports**: D4
**Effort**: Medium
**Dependencies**: S3.1

## Purpose

Make resource capacity visible enough for playtesting by showing current/max values or an equivalent compact capacity indicator.

## Scope
- In: Minimal Food/Energy/Materials capacity display in `ControlPanel`.
- Out: Full economy UI redesign, new art assets, localization overhaul, replacing gold UI.

## Context and Rationale
- W3.1 exposes `PlayerView.resourceCapacity()`, so the panel can consume capacity without recalculating config logic in UI code.
- The existing resource strip already has three compact pills; showing `current/capacity` in each pill is the smallest useful playtest display.
- Labels stay as current Food/Energy/Materials text, with gold left in its existing control panel slot.

## Touchpoints
- Create: None expected.
- Modify: `src/client/hud/layers/ControlPanel.ts`, `tests/client/hud/ControlPanel.test.ts`.

## Acceptance Criteria
- [x] Control panel shows resource current and capacity values.
- [x] Display remains compact on desktop and mobile.
- [x] Gold compatibility display remains visible.
- [x] Values update as player state changes.
- [x] UI code reads capacity from the local `PlayerView`, not from duplicate formula logic.
