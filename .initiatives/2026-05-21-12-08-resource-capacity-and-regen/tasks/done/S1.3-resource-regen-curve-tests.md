## Purpose

Pin the intended troop-shaped resource regen curve so future balance changes do not accidentally flatten or invert it.

## Scope
- In: Relational tests for acceleration up to roughly 42% of capacity and slowdown near cap.
- Out: Exact full-curve snapshot tests, visual graphing, balance tuning.

## Context and Rationale
- Why this exists: The resource curve should keep the same gameplay feel as troop regen, whose peak is around 42% capacity.
- Constraints: Exact values are balance-sensitive and can change, but the curve shape should not accidentally invert.
- Chosen approach: Add relational tests around low, 42%, and high-capacity points instead of brittle snapshots.

## Touchpoints
- Create: None expected.
- Modify: `tests/core/game/Resources.test.ts` or config-focused resource tests.

## Acceptance Criteria
- [x] Regen at a mid-low stockpile is greater than regen near empty.
- [x] Regen around the 42% region is greater than regen near cap.
- [x] Regen at cap is zero.
- [x] Assertions are tolerant of rounding and not brittle float snapshots.
- [x] Tests document the 42% intent directly.
