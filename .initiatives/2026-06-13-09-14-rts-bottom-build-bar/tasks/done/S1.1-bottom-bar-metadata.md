## Scope

- In: Shared metadata for button labels, icons/letters, unit types, descriptions, ordering, and disabled-unit filtering.
- Out: Core unit behavior and placement confirmation.

## Touchpoints

- Create: Optional build-bar metadata helper under `src/client/hud/layers/` or shared HUD module.
