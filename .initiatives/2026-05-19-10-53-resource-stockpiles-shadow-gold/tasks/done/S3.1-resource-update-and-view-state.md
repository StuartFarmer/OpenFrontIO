**Status**: DONE

**Track**: Client state
**Supports**: D3
**Effort**: Medium

## Purpose

Carry resource stockpiles through player updates and client view state without removing existing gold fields.

## Scope
- In: `PlayerUpdate.resources`, full-update emission, diff/apply update support, renderer `PlayerState.resources`, typed replay/live event resource field, `PlayerView.resources()`.
- Out: Replacing all gold UI, replay schema redesign, resource-specific costs or production.

## Touchpoints
- Create: None expected.
- Modify: `src/core/game/GameUpdates.ts`, `src/core/game/GameUpdateUtils.ts`, `src/client/render/types/Renderer.ts`, `src/client/render/types/GameUpdates.ts`, `src/client/view/PlayerView.ts`.

## Acceptance Criteria
- [x] Full player updates include resource stockpiles.
- [x] Partial player update diffs include resources only when changed.
- [x] Client state merge preserves resource values.
- [x] `PlayerView` exposes resources for UI consumers.
- [x] Existing `gold` field remains present.
- [x] Core update payloads keep bigint resource values; renderer state stores numeric values for UI code.
