**Status**: DONE

## Purpose

Migrate worker/passive economic income from scalar `addGold()` to resource-payload `addResources()`.

This is the first production call site migration. The rate remains `goldAdditionRate()` for compatibility, but the mutation should use the new payload API.

## Scope
- In: Player tick income conversion from old gold amount to equal resource payload.
- In: Focused test proving one normal player tick keeps resources and compatibility gold in lockstep.
- Out: Terrain-based resource production and rate changes; renaming stats/config methods.
