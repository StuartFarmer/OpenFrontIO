## Purpose

Place Farmland repeatedly over newly visited valid tiles during a paint stroke using authoritative buildable validation.

## Scope

- In: Tile conversion, buildable lookup, duplicate suppression, affordability/validity rechecks, intent emission, pending validation handling.
- Out: Cursor styling and bottom UI.

## Touchpoints

- Create: `PaintPlacementController` if separating from `BuildPreviewController` reduces risk.
- Modify: `src/client/controllers/BuildPreviewController.ts`, `src/client/Transport.ts` only if contract requires changes.

## Acceptance Criteria

- [x] A stroke emits placement only once per tile visit.
- [x] Invalid or unaffordable tiles do not emit build intents.
- [x] The controller handles async buildable responses without placing stale tiles after cancellation.

## Test Plan

- `test_paint_places_each_new_valid_tile_once` - duplicate suppression.
- `test_paint_ignores_invalid_tiles` - validation gate.
- `test_cancel_drops_pending_paint_confirm` - stale async guard.
