## Purpose

Add Farmland to the chosen core buildable model and make it available to validation and transport without exposing it in the old build menu as the primary entry point.

## Scope

- In: Unit/type definitions, params map, config costs, disabled-unit settings, buildability groups, stats/update paths as required by the chosen model.
- Out: Paint UX and bottom UI integration.

## Touchpoints

- Create: Focused Farmland config/model helpers if needed.

## Acceptance Criteria

- [x] Farmland compiles as a player-buildable 1x1 placeable.
