# S2.4: Paint Cursor And Cancel

**Status**: DOING
**Wave**: W2
**Track**: Client
**Supports**: D3
**Effort**: S
**Dependencies**: S2.1, S2.2

## Purpose

Show a paint-brush cursor while paint mode is active and make right-click cancel cleanly without opening context actions on the same click.

## Scope

- In: Cursor style, right-click cancellation, Escape cleanup, blur cleanup.
- Out: Custom art beyond a CSS cursor or existing icon-backed cursor.

## Touchpoints

- Create: Cursor asset only if CSS/system cursor is insufficient.
- Modify: `src/client/InputHandler.ts`, relevant CSS/assets.

## Acceptance Criteria

- [x] Paint mode sets a visible brush cursor over the map canvas.
- [x] Right-click cancels paint mode and does not open the radial menu for that click.
- [x] Cursor state returns to normal after cancel, blur, or selecting another mode.

## Test Plan

- `test_right_click_cancels_paint_without_context_menu` - cancellation consumes the click.
- `test_paint_cursor_resets` - cleanup state test where feasible.
