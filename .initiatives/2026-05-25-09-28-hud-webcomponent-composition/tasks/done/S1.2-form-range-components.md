**Status**: DONE
**Wave**: W1
**Track**: B
**Supports**: D1, D2, D3
**Effort**: M

## Purpose

Add canonical form controls so future HUD panels do not copy grid rows, labels, native input/select styling, or single range styling.

## Scope

- In: `hud-form-row`, `hud-field-label`, `hud-input`, `hud-select`, `hud-range`.
- Out: Validation frameworks, form state management, custom select menus.

## Touchpoints

- Create: None unless component splitting is needed.
- Modify: `src/client/hud/ui/HudComponents.ts`.

## Acceptance Criteria

- [x] Form row aligns label/control consistently.
- [x] Input/select/range use scoped styles.
- [x] Range emits a stable value-change event or supports native `input` delegation clearly.

## Test Plan

- `npx tsc --noEmit` - verify component typing.
- `npx eslint src/client/hud/ui` - verify lint for new component code.
