## Purpose

Provide concise, HUD-kit-based live diagnostics that make biomass and troop tuning observable during sandbox runs.

## Scope

- In: Active preset summary, current player resources/capacity, biomass-supported troop cap, effective troop cap, troops, troop delta/rate, HUD stat/pill/meter/table primitives.
- Out: Full analytics dashboard, charting framework, replay/stat persistence.

## Touchpoints

- Create: possible `src/client/sandbox/SandboxDiagnostics.ts`
- Modify: `src/client/sandbox/SandboxBalancer.ts`, possibly consume `PlayerView`/HUD state.

## Acceptance Criteria

- [x] Diagnostics identify the active mechanics preset separate from pending values.
- [x] Current player resource and population metrics are visible during a run.
- [x] Diagnostics do not require changes to normal HUD contracts unless strictly necessary.
- [x] No diagnostics are persisted to archive/achievement/stat paths.
- [x] Diagnostics use HUD indicators/data-display primitives such as `hud-pill`, `hud-meter`, `hud-stat-grid`, `hud-table`, or catalog-equivalent components where applicable.
