## Purpose

Factor or reuse single-player `GameStartInfo` construction so `/sandbox` can start real local games without duplicating fragile modal logic.

## Scope

- In: Shared builder for local solo game config, player identity/cosmetics inputs, bots/nations/map/difficulty/options, mechanics injection.
- Out: Full SinglePlayerModal redesign, public/private lobby config mutation.

## Touchpoints

- Create: possible helper under `src/client/sandbox/` or `src/client/utilities/`.
- Modify: `src/client/SinglePlayerModal.ts` if extracting shared construction is cleaner.

## Acceptance Criteria

- [x] Sandbox can construct a valid `GameStartInfo` with mechanics config.
- [x] Existing solo modal behavior remains unchanged.
- [x] Builder supports World-map isolated settings and bot/nation scenario settings.
- [x] Builder does not introduce archive/achievement/stat behavior.
