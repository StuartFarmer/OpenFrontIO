**Status**: DONE
**Wave**: W3
**Track**: Preset UX
**Supports**: D4
**Effort**: M
**Dependencies**: S3.1

## Purpose

Add copy/paste JSON export and import for pending mechanics presets with schema validation and clear errors, using HUD kit surfaces/actions.

## Scope

- In: Textarea or equivalent JSON surface, export formatting, paste/import parse, Zod validation, error display, HUD surface/action/feedback primitives where available.
- Out: Named presets, localStorage persistence, file input, private-lobby sharing.

## Touchpoints

- Create: possible `src/client/sandbox/SandboxPresetJson.ts`
- Modify: `src/client/sandbox/SandboxBalancer.ts`, HUD kit feedback primitive only if the catalog lacks a reusable error/alert pattern needed here.

## Acceptance Criteria

- [x] Exported JSON round-trips into equivalent pending mechanics values.
- [x] Invalid JSON syntax is rejected with a visible error.
- [x] Schema-invalid values are rejected with useful messages.
- [x] Import never mutates an active run directly.
- [x] JSON controls and action buttons use HUD primitives where possible.

## Test Plan

- New sandbox component test - export/import round trip.
- New sandbox component test - invalid JSON and invalid schema errors.
