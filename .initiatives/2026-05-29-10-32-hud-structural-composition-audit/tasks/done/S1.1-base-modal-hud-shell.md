# S1.1: Base Modal HUD Shell

**Status**: DONE
**Wave**: W1
**Track**: Modal Foundation
**Supports**: D1
**Effort**: Medium
**Dependencies**: None

## Purpose
Move the shared modal base path from legacy `o-modal` structure to HUD modal primitives while preserving behavior.

## Scope
- In: `src/client/components/BaseModal.ts`, `src/client/components/baseComponents/Modal.ts`, modal header/body/footer composition.
- Out: Modal content redesign.

## Touchpoints
- Create: none expected.
- Modify: `BaseModal.ts`, possibly `Modal.ts`.

## Acceptance Criteria
- [x] `BaseModal` renders `hud-modal-shell` family primitives directly or through a clearly temporary compatibility bridge.
- [x] Open/close, backdrop click, inline mode, hide header, hide close, max-width, tabs, and body scroll locking remain equivalent.
- [x] Existing subclasses require minimal or no API changes.

## Test Plan
- `npx tsc --noEmit --pretty false` - typecheck shared modal API.
- Manual smoke: open/close settings, help, account, single-player, host, join, and leaderboard modals.

## Working Notes
- Planning baseline created.
- Started implementation.
- `BaseModal` now renders `hud-modal-shell`, `hud-modal-header`, `hud-tabs`, and `hud-modal-body` directly.
- Moved body scroll lock accounting from legacy `o-modal` into `BaseModal`.
- Removed old subclass assumptions around `modalEl.open()`, `modalEl.close()`, and `modalEl.onClose`.
- Added flex layout to `hud-modal-shell` dialog so HUD modal bodies can scroll within bounded dialogs.
- `npx tsc --noEmit --pretty false` passes after S1.1.
