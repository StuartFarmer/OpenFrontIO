**Status**: DONE

## Purpose

Create a reusable HUD primitive for the runtime game layout shell.

## Scope

- In: fixed bottom center stack, right event/chat stack, top-right sidebar stack, safe-area padding, responsive grid behavior.
- Out: Individual control-panel, events, chat, build-menu, player-panel internals.

## Touchpoints

- Create: likely `hud-game-shell` / `hud-game-layout` in `HudComponents.ts` or a dedicated HUD component file.
- Modify: `HudComponents.ts`, HUD UI exports, UI kit documentation/demo.

## Acceptance Criteria

- [x] New primitive exposes slots for app/canvas, center HUD, side HUD, top-right HUD, and overlays.
- [x] Existing responsive behavior can be represented without copy-pasting raw shell classes.
- [x] Primitive appears in `/ui-kit` or HUD catalog/demo.

## Test Plan

- `npx tsc --noEmit --pretty false` - compile new primitive.
- UI kit smoke: verify primitive renders non-empty demo.
