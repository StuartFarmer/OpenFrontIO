## Purpose

Compose homepage chrome from HUD layout primitives while keeping media and links intact.

## Scope

- In: `DesktopNavBar.ts`, `MobileNavBar.ts`, `Footer.ts`, `MainLayout.ts`.
- Out: Brand/logo media replacement, social link target changes.

## Touchpoints

- Create: possible HUD page/chrome primitive if repeated layout cannot compose cleanly.
- Modify: listed files and `HudComponents.ts` / UI kit if a new primitive is needed.

## Acceptance Criteria

- [x] Navigation and footer surfaces use HUD surface/toolbar/row primitives where appropriate.
- [x] Logo, wiki, GitHub, Discord, and Reddit media remain visually correct.
- [x] Main layout preserves responsive scroll area and in-game hiding behavior.
