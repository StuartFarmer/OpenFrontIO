**Status**: DONE

**Track**: Client math
**Supports**: D3
**Effort**: M

## Purpose

Compute a smooth, capped normalized concentration value from drag distance relative to the player's border max-distance contour.

## Scope

- In: Max-distance calculation, nearest-border or border-outline distance measurement, normalized sigmoid mapping, clamping.
- Out: DOM event arbitration and runtime front-share application.

## Touchpoints

- Create: Optional client helper module if testability warrants it.
- Modify: `src/games/foundation/client/FoundationPage.ts`, `tests/games/foundation/client/FoundationPage.test.ts` or a new focused helper test.

## Acceptance Criteria

- [ ] Distance at zero maps to no extra concentration.
- [ ] Distance at or beyond max distance maps to maximum concentration.
- [ ] Mid-range values are smooth and monotonic.

## Test Plan

- `drag focus normalization test` - asserts endpoints, monotonicity, and cap.
- `border max distance test` - asserts stable max distance from representative owned territory.
