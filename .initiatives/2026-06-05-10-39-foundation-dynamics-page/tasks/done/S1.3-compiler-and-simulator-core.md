## Purpose

Compile portable dynamics graphs into executable stock-flow models and run deterministic tick simulations with traces.

## Scope

- In: Graph validation, topological evaluation, StockFlowModel compilation, simulator tick loop, trace frames.
- Out: React Flow rendering, localStorage, chart UI.

## Touchpoints

- Create: `src/core/systems/dynamics/DynamicsCompiler.ts`
- Create: `src/core/systems/dynamics/DynamicsSimulator.ts`
- Create: `tests/core/systems/dynamics/compiler.test.ts`
- Create: `tests/core/systems/dynamics/simulator.test.ts`
- Modify: `src/core/systems/StockFlowSystem.ts` only if existing primitives need a compatible extension.

## Acceptance Criteria

- [x] Flow nodes apply signed amounts to stock nodes.
- [x] Stock min/max clamps are honored by simulation.
- [x] Trace frames include tick, values, stocks, flows, stock deltas, and overflow.
- [x] Invalid graphs fail with actionable errors.

## Test Plan

- `compiler_maps_single_stock_graph_to_stock_flow_model` - proves graph-to-runtime mapping.
- `simulator_records_clamped_stock_overflow` - proves capacity behavior.
- `simulator_uses_scenario_input_overrides` - proves editable external values affect ticks.
