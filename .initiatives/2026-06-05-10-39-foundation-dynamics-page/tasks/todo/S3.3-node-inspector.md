## Purpose

Let users inspect and edit selected node names, config values, units, and operation-specific fields.

## Scope

- In: Selected node panel, type-specific controls, validation messages, live external input/parameter edits.
- Out: Full expression language, multi-select bulk editing, player-facing polish.

## Touchpoints

- Create: `src/games/foundation/dynamics/react/DynamicsInspector.tsx`
- Modify: `src/games/foundation/dynamics/react/DynamicsFlowEditor.tsx`

## Acceptance Criteria

- [ ] Node names are editable without changing ids.
- [ ] Input and parameter nodes expose sliders/numeric controls.
- [ ] Math and activation nodes expose constrained operation controls.
- [ ] Stock nodes expose initial/min/max/capacity config.
