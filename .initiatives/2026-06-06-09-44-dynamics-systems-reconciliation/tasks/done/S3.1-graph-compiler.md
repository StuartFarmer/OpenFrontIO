## Purpose

Compile canonical current-style dynamics graphs into executable runtime structures once, so game systems do not evaluate raw graph JSON or React Flow objects ad hoc.

## Scope

- In: Graph validation, topological ordering, expression/function compilation, stable value addresses, compile diagnostics.
- Out: Restoring the deleted historical compiler module.
