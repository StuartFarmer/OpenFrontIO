## Purpose

Create a typed adapter that maps Foundation runtime state into compiled graph inputs/sinks and maps compiled outputs back into runtime metrics and player updates.

## Scope

- In: Player/map/parameter reads, food stock sink state, troop sink state or population output, runtime metric extraction.
- Out: Direct UI changes.
