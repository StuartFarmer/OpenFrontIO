# S1.2: Runtime Evaluation And Validation

**Status**: DONE
**Wave**: W1
**Track**: Foundation
**Supports**: D1
**Effort**: L
**Dependencies**: S1.1

## Purpose

Implement a deterministic runtime/compiler that validates systems, resolves
dependency order, evaluates outputs and flows, sums deltas by stock, and applies
stock updates once per tick.

## Scope

- In: Runtime compile/evaluate path, validation errors, dependency sorting,
  stock delta application, clamps.
- Out: Player integration, resource bigint adapter, sandbox UI.

## Touchpoints

- Create: `src/core/systems/StockFlowRuntime.ts`
- Create: `src/core/systems/StockFlowCompiler.ts`
- Create: `tests/core/systems/StockFlowRuntime.test.ts`
- Modify: `src/core/systems/StockFlowSystem.ts`

## Acceptance Criteria

- [x] Duplicate stock ownership is rejected.
- [x] Duplicate output addresses are rejected.
- [x] Missing declared reads are rejected.
- [x] Flows targeting unknown or non-stock addresses are rejected.
- [x] Multiple flows to one stock are summed and applied once.
