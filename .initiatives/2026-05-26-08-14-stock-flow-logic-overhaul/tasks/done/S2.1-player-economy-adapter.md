# S2.1: Player Economy Adapter

**Status**: DONE
**Wave**: W2
**Track**: Adapter
**Supports**: D2, D3
**Effort**: L
**Dependencies**: S1.2, S1.4

## Purpose

Bridge current `Game`, `Player`, `Config`, resources, troops, tiles, units, and
mechanics config into stock-flow runtime inputs and stock state.

## Scope

- In: Adapter for reading/writing current player economy stocks and exposing
  external inputs such as tiles owned, terrain weights, player type, difficulty,
  and active attacks.
- Out: Replacing `PlayerExecution.tick()` mutation.

- Modify: None expected outside tests.

## Acceptance Criteria

- [x] Adapter can read current troop/population and resource stock values.
- [x] Adapter can expose territory, terrain, player type, and mechanic
      parameters as addressable inputs.
- [x] Adapter can convert runtime resource deltas back to `ResourceStockpile`
      deltas without precision drift for current values.
