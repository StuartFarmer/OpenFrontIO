# S5.1: Sandbox Model-Driven Graphs

**Status**: DONE
**Wave**: W5
**Track**: Sandbox
**Supports**: D5
**Effort**: L
**Dependencies**: S4.4

## Purpose

Drive sandbox population/resource/food graphs from stock-flow model outputs
instead of duplicated local formulas.

## Scope

- In: Graph data generation through runtime/model evaluation; controls for new
  food and wartime parameters.
- Out: General-purpose visual model editor.

## Touchpoints

- Modify: `src/client/sandbox/SandboxBalancer.ts`
- Modify: `tests/client/sandbox/SandboxBalancer.test.ts`

## Acceptance Criteria

- [x] Population, food stock, food ratio, births, deaths, and wartime food
      pressure graphs use model outputs.
- [x] Existing sandbox JSON import/export still works.
- [x] The graph axis ranges remain suitable for 2,500 to 562,500 tile scales.
