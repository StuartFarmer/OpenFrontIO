## Purpose

Define the typed contract for addressable values, stock ownership, system
classes, declared reads, outputs, flows, parameters, and evaluation context.

## Scope

- In: Core TypeScript types for `ValueAddress`, `StockFlowSystem`,
  stock/parameter/output/flow definitions, and one-tick evaluation context.
- Out: Runtime implementation, gameplay integration, food behavior.
