## Purpose

Create a mdBook source layout that keeps existing docs visible and leaves stable slots for generated mechanics pages.

## Scope
- In: Add `docs/src/SUMMARY.md`; add wrapper or moved chapters for existing `Architecture`, `API`, and `Auth` docs; reserve a generated reference section.
- Out: Rewriting existing docs, adding generated mechanics content, publishing configuration.

## Touchpoints
- Create: `docs/src/SUMMARY.md`
- Create: `docs/src/*.md` wrapper pages as needed
- Modify: `docs/Architecture.md`, `docs/API.md`, `docs/Auth.md` only if the chosen layout requires moves or include-safe formatting

## Acceptance Criteria
- [ ] Existing docs are reachable in the mdBook table of contents.
- [ ] A placeholder mechanics reference section exists for generated pages.
- [ ] Existing Markdown remains readable in GitHub without requiring mdBook.

## Test Plan
- `npm run docs:build` - verifies navigation and chapter paths.
- `npx prettier --check docs book.toml package.json` - verifies formatting for touched docs/config.
