# S4.1: Adjustable Game Config Catalog

**Status**: TODO
**Wave**: W4
**Track**: Adjustable metadata
**Supports**: D4
**Effort**: Medium
**Dependencies**: W2

## Purpose

Create a shared metadata surface for player-facing adjustable game configuration and generate docs from it.

## Scope
- In: Defaults, min/max bounds, units, label keys, public modifiers, host cheats, disabled units, lobby/single-player distinctions.
- Out: Redesigning lobby UI, changing schema behavior, adding new configurable options.

## Touchpoints
- Create: `src/core/configuration/GameConfigMetadata.ts` or equivalent
- Modify: `src/core/Schemas.ts` only if schema can consume shared bounds safely
- Modify: `src/client/SinglePlayerModal.ts`, `src/client/HostLobbyModal.ts`, and helpers only if low-risk metadata reuse is practical
- Modify: generated adjustable-parameter docs

## Acceptance Criteria
- [ ] Generated docs list adjustable settings with default, bounds, units, and gameplay effect.
- [ ] Schema validation and UI defaults are either metadata-backed or clearly cross-referenced for future consolidation.
- [ ] Host cheats are documented separately from normal game rules.

## Test Plan
- `npx tsc --noEmit` - verifies type safety across client/core imports.
- `npm run build-prod` - verifies client bundling remains valid.
- `npm run docs:generate && npm run docs:check` - verifies adjustable docs are fresh.
