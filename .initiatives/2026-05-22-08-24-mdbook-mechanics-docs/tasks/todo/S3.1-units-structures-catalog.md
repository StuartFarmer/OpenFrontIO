## Purpose

Move first-pass unit and structure balance data into metadata and generate reference docs from it.

## Scope
- In: Costs, construction durations, max health, upgrade flags, caps, disabled-unit behavior notes, structure distance/range values.
- Out: Rebalancing values, replacing every `Config` method, UI changes.

## Touchpoints
- Create: unit/structure mechanics metadata file
- Modify: `src/core/configuration/Config.ts` only where simple values can safely delegate to metadata
- Modify: generated mechanics docs
- Create or modify: focused config/unit tests

## Acceptance Criteria
- [ ] Generated docs include unit costs and construction durations for City, Factory, Port, DefensePost, MissileSilo, SAMLauncher, Warship, AtomBomb, HydrogenBomb, MIRV, and transport-related units.
- [ ] Existing `Config.unitInfo()` behavior is preserved.
- [ ] Disabled-unit and cap behavior is documented where relevant.

## Test Plan
- `npx vitest run tests/core/configuration` - verifies config behavior.
- `npm run docs:generate && npm run docs:check` - verifies docs are generated from metadata.
