# S2.1: Mechanics Metadata Model

**Status**: TODO
**Wave**: W2
**Track**: Shared foundation
**Supports**: D2
**Effort**: Medium
**Dependencies**: W1

## Purpose

Define the typed source-of-truth shape for mechanics entries that can be consumed by runtime code and docs generation.

## Scope
- In: Types for mechanics categories, values, units, formulas, source references, examples, tags, and notes; initial empty registry or seed entries.
- Out: Broad migration of `Config` values, generated pages, CI.

## Touchpoints
- Create: `src/core/configuration/MechanicsCatalog.ts` or `src/core/mechanics/*`
- Create: tests for metadata validation if the model includes runtime validators
- Modify: `tsconfig` only if needed for generator imports

## Acceptance Criteria
- [ ] Metadata types are pure TypeScript and side-effect-free.
- [ ] The model supports simple literals, bigint display values, formulas, and source references.
- [ ] The model is explicit enough to avoid AST scraping for first-pass generated docs.

## Test Plan
- `npx tsc --noEmit` - verifies type safety.
- `npx vitest run tests/core/configuration` - verifies nearby config tests remain stable if touched.
