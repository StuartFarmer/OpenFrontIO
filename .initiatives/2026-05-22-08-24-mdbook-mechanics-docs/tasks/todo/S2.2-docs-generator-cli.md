## Purpose

Add a TypeScript generator that reads mechanics metadata and writes deterministic mdBook Markdown reference pages.

## Scope
- In: Generator CLI, stable sorting, Markdown table rendering, formula rendering, source-link rendering, generated file header.
- Out: Full mechanics coverage, CI integration, UI metadata alignment.

## Touchpoints
- Create: `scripts/generate-mechanics-docs.ts` or equivalent
- Create: generated docs directory under `docs/src/reference/generated/`
- Modify: `package.json`

## Acceptance Criteria
- [ ] `npm run docs:generate` writes deterministic generated Markdown.
- [ ] Generated files clearly identify themselves as generated.
- [ ] The generator can run in Node without importing browser-only client modules.

- `npm run docs:build` - verifies generated pages build in mdBook.
