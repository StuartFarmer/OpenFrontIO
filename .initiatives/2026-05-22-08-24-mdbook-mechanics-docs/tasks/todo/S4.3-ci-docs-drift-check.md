**Status**: TODO
**Wave**: W4
**Track**: CI join
**Supports**: D5
**Effort**: Medium
**Dependencies**: S4.1, S4.2

## Purpose

Add CI validation so mechanics docs are built from the pinned mdBook version and generated output cannot drift silently.

## Scope
- In: GitHub Actions docs job or integration into existing CI, pinned mdBook install/provisioning, docs build and check commands.
- Out: Docs publishing, release automation, broad CI restructuring.

## Touchpoints
- Modify: `.github/workflows/ci.yml`
- Modify: `package.json`
- Modify: docs workflow page if CI commands differ from local commands

## Acceptance Criteria
- [ ] CI installs or provisions the pinned mdBook version.
- [ ] CI runs docs generation freshness check and mdBook build.
- [ ] CI failure messages tell contributors which local docs command to run.

## Test Plan
- `npm run docs:check` - verifies generated docs freshness locally.
- `npm run docs:build` - verifies mdBook build locally.
- `npm run lint && npm run test -- --run` - verifies existing CI-adjacent commands still pass.
