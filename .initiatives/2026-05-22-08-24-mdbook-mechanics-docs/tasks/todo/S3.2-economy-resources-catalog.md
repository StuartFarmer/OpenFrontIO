## Purpose

Document economy, troop growth, resource capacity, regeneration, and trade-related formulas from code-owned metadata.

## Scope
- In: Starting manpower, max troop formulas, troop growth, resource capacity, terrain production weights, resource regeneration, gold addition, train/trade ship reward formulas.
- Out: New economy mechanics, UI displays, balance changes.

## Touchpoints
- Create: economy/resource mechanics metadata file
- Modify: `src/core/configuration/Config.ts` and `src/core/game/Resources.ts` only where metadata extraction is low-risk
- Modify: generated economy docs
- Create or modify: focused economy/resource tests

## Acceptance Criteria
- [ ] Generated docs explain formulas with inputs, units, and example outputs where literal tables are insufficient.
- [ ] Existing economy behavior remains unchanged.
- [ ] The existing economy prose can link to generated constants rather than duplicating them manually.

## Test Plan
- `npx vitest run tests/core/configuration tests/core/game` - verifies nearby economy/resource behavior.
- `npm run docs:generate && npm run docs:check` - verifies generated economy docs are fresh.
