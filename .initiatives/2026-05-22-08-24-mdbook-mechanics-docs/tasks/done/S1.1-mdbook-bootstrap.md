## Purpose

Add the minimal mdBook configuration and npm command surface needed to build and serve documentation locally.

## Scope
- In: Add `book.toml`; add npm scripts for docs build/serve; define a pinned mdBook version in project docs or helper script.
- Out: Generated mechanics content, CI integration, mechanics metadata.

## Touchpoints
- Create: `book.toml`
- Modify: `package.json`
- Modify: docs setup notes created in S1.3 if needed

## Acceptance Criteria
- [x] `npm run docs:build` shells out to `mdbook build` with the intended book root.
- [x] `npm run docs:serve` shells out to `mdbook serve` for local browsing.
- [x] A missing `mdbook` binary produces a clear path to install the pinned version.

## Test Plan
- `npm run docs:build` - verifies the mdBook project builds.
- `npm run build-prod` - confirms npm script changes did not break existing build scripts.
