## Purpose

Define the canonical state snapshot needed to prove legacy and systems paths
are behaviorally equivalent.

- In: Snapshot schema for players, attacks, units, resources, troop counts,
  ownership, updates, packed tile updates, hash, and selected stats.
- Out: New systems runtime implementation.

- Modify: None expected outside tests.
