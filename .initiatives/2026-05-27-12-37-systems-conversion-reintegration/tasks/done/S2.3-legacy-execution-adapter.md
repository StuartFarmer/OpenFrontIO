# S2.3: Legacy Execution Adapter

**Status**: DONE
**Wave**: W2
**Track**: Main
**Supports**: D2
**Effort**: M
**Dependencies**: S2.1, S2.2

## Purpose

Allow existing `Execution` objects to run through the systems scheduler without
changing their behavior.

## Scope

- In: Adapter for `init`, `tick`, active filtering, spawn-phase behavior, and
  inactive removal semantics.
- Out: Refactoring individual execution classes.

## Touchpoints

- Create: `src/core/systems/LegacyExecutionSystem.ts`
- Modify: `src/core/game/GameImpl.ts`, `tests/core/game/GameImpl.test.ts`

## Acceptance Criteria

- [x] Legacy executions run with the same init/tick order as before.
- [x] `game.addExecution(...)` remains source-compatible.

## Test Plan

- `legacy_execution_adapter_preserves_tick_order` - validates ordering.
- `legacy_execution_adapter_removes_inactive` - validates active filtering.
